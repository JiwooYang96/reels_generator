# Scene catalogue

Generated by `npx tsx scripts/catalog.ts` from `src/scenes/registry.ts`. Do not edit by hand.

Every plan scene has: `type`, `seconds` (1-8), `caption` (words; one or two `key: true`; `br: true` starts line 2), optional `theme` ("dark" | "light"), `source` (required for data scenes), and `props` as listed below. Scene 1 must be an `open.*` scene of 3 s or less.

## `open.logo`

OPENING. The company logo (by ticker) drops in with a shake and burst, ticker and name under it, then the big move (e.g. "−4.2%"). One-company stories.

Default theme: dark. Source line: not needed.

- `big`: string
- `sub` (optional): string
- `tone` (optional): "bad" | "good" | "gold", default "bad"
- `ticker`: string

## `open.burst`

OPENING. Big number/word explodes in with a particle burst and camera shake. Shock stats.

Default theme: dark. Source line: not needed.

- `big`: string
- `sub` (optional): string
- `tone` (optional): "bad" | "good" | "gold", default "bad"

## `open.ticker`

OPENING. Three rows of scrolling ticker tape, then a crash (or surge) line slashes across and the big text slams. Market moves.

Default theme: dark. Source line: not needed.

- `big`: string
- `sub` (optional): string
- `tone` (optional): "bad" | "good" | "gold", default "bad"
- `tickers`: array of objects, 3-12 items, each: `s` string, `v` string

## `open.spotlight`

OPENING. A spotlight sweeps across a dark stage and lands on the big text. Reveals, "the number nobody is talking about".

Default theme: dark. Source line: not needed.

- `big`: string
- `sub` (optional): string
- `tone` (optional): "bad" | "good" | "gold", default "bad"

## `open.cashRain`

OPENING. Banknotes rain down (they burn red for bad news) behind the big text. Money lost, money made, prices.

Default theme: dark. Source line: not needed.

- `big`: string
- `sub` (optional): string
- `tone` (optional): "bad" | "good" | "gold", default "bad"

## `open.breaking`

OPENING. A red band ("BREAKING" or custom label) wipes in, then the big text glitches in with an RGB split. Fresh news.

Default theme: dark. Source line: not needed.

- `big`: string
- `sub` (optional): string
- `tone` (optional): "bad" | "good" | "gold", default "bad"
- `label` (optional): string, default "BREAKING"

## `counter`

Big number racing from `from` to `to` with a progress bar; the hook or headline stat.

Default theme: dark. Source line: required.

- `label`: string
- `from` (optional): number, default 0
- `to`: number
- `prefix` (optional): string, default ""
- `suffix` (optional): string, default ""
- `sign` (optional): "" | "+" | "−", default ""
- `decimals` (optional): integer, default 0
- `tone` (optional): "bad" | "good" | "gold", default "gold"
- `sub` (optional): string
- `logo` (optional): string

## `priceSlam`

Old value gets struck through, new value tag slams on with a shake. Price changes, before/after.

Default theme: dark. Source line: required.

- `label`: string
- `sublabel` (optional): string
- `oldValue`: string
- `newValue`: string
- `logo` (optional): string

## `compareBars`

2-4 vertical glass bars filling to scale with their values, optional badge (e.g. "2.2x"). Then vs now, A vs B.

Default theme: light. Source line: required.

- `title`: string
- `bars`: array of objects, 2-4 items, each: `label` string, `value` number, `display` string, `highlight`? boolean, `logo`? string
- `badge` (optional): string

## `lineMove`

A line drawing down (or up) from a labelled start point to a % badge. Index or price moves. Shape is illustrative and says so.

Default theme: light. Source line: required.

- `title`: string
- `startLabel`: string
- `direction`: "down" | "up"
- `badge`: string
- `note` (optional): string, default "line shape illustrative · endpoints from source"

## `scoreboard`

Rows of names with green up / red down values popping in; one hero row outlined. Index closes, rankings, winners vs losers.

Default theme: light. Source line: required.

- `title`: string
- `rows`: array of objects, 2-5 items, each: `name` string, `value` string, `up` boolean, `hero`? boolean, `logo`? string
- `footnote` (optional): string

## `stampList`

App/store window with rows; red stamps (REMOVED, BANNED, DELAYED...) slam onto chosen rows. Pulled products, cancelled deals.

Default theme: light. Source line: required.

- `windowTitle`: string
- `rows`: array of objects, 1-4 items, each: `name` string, `value` string, `stamped`? boolean, `logo`? string
- `stamp` (optional): string, default "REMOVED"
- `footnote` (optional): string

## `timeline`

Gold line with 2-4 dated circles popping in (labels up to 5 chars, e.g. JAN), plus an optional explainer card. Repeated events, patterns.

Default theme: dark. Source line: required.

- `items`: array of objects, 2-4 items, each: `label` string, `value` string
- `note` (optional): string
- `noteHighlight` (optional): string

## `calendarCta`

Calendar card for an upcoming date + pulsing follow line. Use as the open-loop ending ("the next test lands Friday").

Default theme: dark. Source line: not needed.

- `day`: string, max 4 chars
- `date`: string
- `event`: string
- `cta` (optional): string, default "Follow so you see what happens →"

## `barRank`

3-6 horizontal bars ranked largest first, growing in turn; highlight one. Rankings, biggest movers, market share. Negative values draw red.

Default theme: light. Source line: required.

- `title`: string
- `bars`: array of objects, 3-6 items, each: `label` string, `value` number, `display` string, `highlight`? boolean, `logo`? string

## `donut`

Donut chart drawing its segments in turn with a big centre figure; legend below. Shares of a whole.

Default theme: light. Source line: required.

- `title`: string
- `segments`: array of objects, 2-5 items, each: `label` string, `value` number, `highlight`? boolean
- `center`: string
- `centerSub` (optional): string

## `grid100`

10x10 grid of squares; `highlight` of them light up. "Only 3 in 100...", odds, shares of people.

Default theme: light. Source line: required.

- `highlight`: integer
- `label`: string
- `sub` (optional): string
- `tone` (optional): "bad" | "good" | "gold", default "gold"

## `versus`

Split screen A vs B with a VS badge; the winner side glows gold. Two companies, two countries, two policies.

Default theme: dark. Source line: required.

- `left`: object {`name` string, `value` string, `caption`? string, `logo`? string}
- `right`: object {`name` string, `value` string, `caption`? string, `logo`? string}
- `winner` (optional): "left" | "right" | "none", default "none"

## `chapters`

Numbered cards with locks and a progress bar: the visible open loop ("4 things..."). `unlocked` shows how many are revealed.

Default theme: light. Source line: not needed.

- `items`: array of string, 3-5 items
- `unlocked` (optional): integer, default 0

## `headline`

A news-headline card (outlet name as plain text, no logos) with one phrase marker-highlighted. Quoting what was reported.

Default theme: light. Source line: required.

- `outlet`: string
- `date`: string
- `text`: string
- `highlight` (optional): string
